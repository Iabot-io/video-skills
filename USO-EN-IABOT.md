# Usar estas skills en IAbot.io

IAbot.io permite crear empleados IA, asignarles herramientas y darles encargos con
los archivos y el contexto de la organización. Un empleado puede tener varias
skills; cada una resuelve un trabajo concreto.

1. Abre **Skills** en tu espacio de IAbot.io; `/skills` abre la biblioteca desde el chat.
2. Localiza la habilidad pública cuando esté indexada y revisa origen, revisión,
   recursos y requisitos. Si todavía no aparece, utiliza **Crear** para incorporar
   sus instrucciones y referencias con la licencia correspondiente.
3. Elige si se aplica a la **empresa**, a un departamento o a empleados concretos.
4. Da acceso solo a los archivos y aplicaciones necesarios. Las conexiones de
   correo, CRM, ERP o calendario se autorizan por separado.
5. La opción **Usar** prepara el borrador: añade las entradas indicadas en el
   `SKILL.md`, adapta periodo, alcance y formato y pulsa **Enviar**. Elegir una
   skill no inicia por sí solo el trabajo.
6. Revisa el resultado con los criterios de la habilidad. Una importación no prueba
   por sí sola que el empleado pueda ejecutar el recorrido completo.

Los planes con ordenador disponen de un entorno Linux por organización. Importar
una skill no instala sus programas ni ejecuta automáticamente los scripts. Si se
necesita software, comprueba primero el inventario del ordenador y la guía de
instalación del fabricante; conserva las aplicaciones y trabajos existentes.

La importación y asignación requieren los permisos de gestión correspondientes.
Cada empleado solo puede utilizar las habilidades que le están permitidas. Una
propuesta pendiente de revisión no equivale a una skill activa para toda la empresa.

Las instrucciones también pueden usarse con otros agentes compatibles con
[Agent Skills](https://agentskills.io/specification). No necesitan una cuenta de
IAbot.io para leerlas ni están limitadas a un único proveedor de modelos.
